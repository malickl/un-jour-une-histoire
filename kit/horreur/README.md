# Format « Horreur interactive » (essai « La gare », 03/11/2026)
Moteur pseudo-3D numpy (couloirs en perspective, lumières, brouillard, grain). Voix : scripts `scripts/horreur_<nom>_hN.txt` avec 1re ligne `#STYLE rate=-4% pitch=-5Hz`.
Structure : 3 choix max, un mauvais choix par étape (position 1/2 variable), compte à rebours, écran MORT, rebobinage. Commandes : `python3 build.py plan|video|audio` (voir build.py, polices Anton dans fonts/).
